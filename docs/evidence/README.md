# Public Nile evidence

- [`registry-deployment.json`](registry-deployment.json) records the independently verified ReceiptRegistry deployment.
- [`energydesk-receipt.json`](energydesk-receipt.json) records the canonical fixture decision payload, digest, public transaction and independent verification result.

These files contain public testnet data only. They contain no private key, API key, raw signed transaction or seed phrase.

The receipt proves that the test wallet committed the displayed decision digest on Nile. It does not prove an Energy order, payment, locked quote or delivery.
