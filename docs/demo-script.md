# Three-minute demo script

| Time | Action | Line to say |
|---|---|---|
| 0:00–0:20 | Show the 86-worker event-close request | “The deadline is fixed; one missed payment pushes settlement into another day.” |
| 0:20–0:55 | Generate the fixture plan | “Neither provider has enough inventory alone, so the optimizer splits 5.59 million Energy.” |
| 0:55–1:20 | Expand the full cost | Show rental, activation, service and per-order reserves. |
| 1:20–1:50 | Simulate quote expiry and re-plan | “The old allocation turns red before anyone copies it into an order screen.” |
| 1:50–2:15 | Show live-source mode or saved live screenshot | State the capture time and avoid presenting an old quote as current. |
| 2:15–2:40 | Copy the handoff brief | Point out source times, assumptions, digest and selected allocation. |
| 2:40–3:00 | Open the confirmed Nile receipt | “This commits the fixture decision; Energy was not ordered or delivered.” |

If either live provider is unavailable, keep the failure visible and continue with the clearly labeled fixture flow.
